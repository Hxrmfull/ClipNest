# ClipNest

Замена встроенного буфера обмена Windows (Win+V) без лимитов на количество записей и размер.

## Что умеет

| | Win+V | ClipNest |
|---|---|---|
| Записей в истории | 25 | без ограничений (настраивается) |
| Размер записи | до 4 МБ | без ограничений |
| После перезагрузки | пропадает (кроме закреплённых) | сохраняется (SQLite) |
| Поиск | нет | мгновенный, по нескольким словам |
| Фильтры | нет | текст / ссылки / картинки / файлы / закреплённые |

Ещё умеет:
- открывается под текстовым курсором, а если программа его не сообщает, то рядом с мышью;
- вставка с форматированием (HTML/RTF) или чистым текстом (Shift+Enter);
- быстрая вставка Ctrl+1…9;
- преобразования текста при вставке: ВЕРХНИЙ, нижний регистр, без лишних пробелов, в одну строку;
- превью цветов (`#8B5CF6`, `rgb(…)`), крупное превью картинок по наведению;
- видно, из какой программы скопирована запись;
- одинаковые записи не дублируются, а поднимаются наверх;
- **пароли, токены и ключи закрываются спойлером**, как скрытый текст в Telegram (размытие и мерцающие частицы):
  - находит сам: пароли, ключи API (GitHub, OpenAI/Anthropic, AWS, Google, Slack, Stripe, npm…), токены Telegram-ботов, JWT, номера карт (с проверкой по Луну), приватные ключи, строки вида `пароль: …`;
  - под размытием фальшивый текст, так что на скриншоте или демонстрации экрана настоящее содержимое не видно; подсказка и поиск по содержимому отключены;
  - на диске такие записи зашифрованы через Windows DPAPI (расшифровать может только ваша учётная запись), повторы распознаются по HMAC, а не по открытому хешу; удалённые данные затираются (`secure_delete`);
  - любую запись, включая картинку, можно скрыть вручную, и с любой можно снять пометку;
  - **секреты на картинках** (версия с OCR): каждая новая картинка читается распознаванием текста, встроенным в Windows (локально, без интернета), а найденные токены, номера карт и значения после «Пароль:» размываются прямо на превью, остальное видно. Вставляется картинка без размытия. Для старых картинок есть пункт меню «Проверить на секреты». Текст с картинок попадает в поиск;
  - вставленный секрет помечается «не для журнала буфера Windows и облака» и через минуту убирается из буфера (если вы не скопировали что-то другое);
- не сохраняет то, что менеджеры паролей помечают «не для истории» (если выключить, будет сохранять скрытым); есть чёрный список программ;
- тёмная и светлая тема (по умолчанию как в системе), акцентный цвет берётся из Windows;
- интерфейс на русском, английском и китайском, при первом запуске язык берётся из Windows.

## Как встроенный буфер Windows

Окно открывается, не забирая фокус: курсор остаётся в поле, где вы печатали, поэтому вставка по клику или Enter
срабатывает сразу, без переключения окон. Пока окно открыто, стрелки, Enter, Esc, Tab, Del и сочетания ClipNest
перехватываются, а набранные буквы сразу попадают в поиск (в текущей раскладке). Клик в поле поиска включает
обычное редактирование. Окно закрывается после вставки, по Esc, повторному Win+V, клику мимо окна, открытию
«Пуска» или переключению на другую программу. Окно можно перетащить за полосу сверху или любое пустое место.

## Размер окна

Настройки → «Размер окна буфера»:
- **масштаб 80–125%**: текст, карточки и картинки уменьшаются или увеличиваются вместе (например, 80–90% на мониторе
  1080p, если на 2K окно смотрится нормально, а здесь великовато). По нажатию окно сразу показывается рядом с настройками
  в новом размере: Enter или «Готово» оставляет его, Esc возвращает прежний;
- **ширина и высота мышью**: кнопка «Изменить размер мышью» показывает окно с рамкой. Тяните его за любой край или угол,
  переносите за любое место. Enter или «Готово» сохраняет размер, Esc отменяет. Пока идёт растягивание, кнопки масштаба
  меняют размер сразу. «Сбросить» возвращает 420 × 600;
- в обычной работе окно не растягивается, поэтому случайно размер не изменится. Наименьший размер 400 × 380 (при 100%),
  наибольший 90% рабочей области монитора. Размер, подобранный на большом мониторе, на маленьком обрезается до этих 90%:
  в окне просто помещается меньше карточек.

## Язык

Интерфейс на русском, английском и китайском (упрощённом, 简体中文). Язык выбирается сам при первом запуске (установщика
у ClipNest нет): берётся язык интерфейса Windows, а если это не один из трёх, то первый подходящий из списка
предпочитаемых языков (Параметры → Время и язык → Язык). Если подходящего нет, ставится английский; любой китайский,
в том числе традиционный, получает упрощённый. Выбор сохраняется в `settings.json` и дальше меняется только вручную:
Настройки → «Язык».

Поиск находит секреты и картинки по словам на любом из трёх языков («пароль», «password», «密码», «картинка», «image»,
«图片»). Пароли с подписью «密码：» распознаются так же, как «Пароль:».

Разметка проверена автоматически на 1614 вариантах: 3 языка, 5 мониторов (от 2560×1440 до 1280×720 при 150%),
5 масштабов, 6 размеров, обе темы, список, картинки, поиск, пустая история, режим растягивания и окно настроек на
минимальной ширине. Проверка ищет обрезанные и вылезающие за окно элементы, наложения и карточки шире списка
(`--layoutcheck`).

## Клавиши

| Клавиша | Действие |
|---|---|
| Win+V | открыть / закрыть |
| ↑ ↓, PgUp PgDn | выбор |
| Enter / клик | вставить |
| Shift+Enter / Shift+клик | вставить без форматирования |
| Ctrl+1…9 | вставить запись по номеру |
| Ctrl+C | только скопировать, не вставлять |
| Ctrl+P | закрепить / открепить |
| Ctrl+H | показать / скрыть секрет (у обычной записи: скрыть как секрет) |
| Del | удалить |
| Tab / Shift+Tab | переключить фильтр |
| Esc | очистить поиск / закрыть |
| буквы, цифры | поиск (Backspace — стереть, Ctrl+Backspace — очистить) |
| Ctrl+V | вставить текст из буфера в поиск |
| Home / End | первая / последняя запись |
| Правый клик | меню: открыть ссылку, показать в проводнике, преобразования |

## Две версии

| | Обычная | С OCR |
|---|---|---|
| Файл | `publish\ClipNest.exe`, ~3 МБ | `publish-ocr\ClipNest.exe`, ~28 МБ |
| Секреты на картинках | нет | да (распознавание текста Windows, ~50–150 мс на скриншот) |
| Всё остальное | одинаково | одинаково |

Данные у версий общие: можно перейти с одной на другую, история сохранится. Обычная версия правильно показывает
картинки, на которых секреты уже нашла версия с OCR, но новые картинки не проверяет.

## Сборка

```
dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:ClipNestOcr=false -o publish
dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:ClipNestOcr=true -o publish-ocr
```

Нужен .NET 8 Desktop Runtime. Сборка с ReadyToRun: код заранее скомпилирован, поэтому первое открытие после запуска проходит без JIT-паузы.

## Как устроена скорость

- **Хранилище.** Таблица `items` компактная: превью до 3000 символов и метаданные, ключ поиска в последней колонке. Полный текст, HTML, RTF и списки файлов лежат в `bodies` и читаются только при вставке. Первая страница истории загружается за ~0,3 мс даже при 20 000 записях и мегабайтных копиях из Word.
- **Поиск.** Для слов от 3 символов используется триграммный индекс SQLite FTS5 (поиск подстроки, ~0,1–1 мс). Для коротких или очень частых слов обычный просмотр в порядке показа, он находит первую страницу почти сразу.
- **Окно.** Обычное, не «слоёное»: скругление, рамку и тень рисует сама Windows 11. Прозрачное окно копировало бы каждый кадр из видеокарты в процессор. Окно создаётся и прогревается при запуске.
- **Перехват Win+V** работает в отдельном потоке: Windows ждёт ответа на каждое нажатие клавиши в системе, поэтому он не должен стоять в очереди за интерфейсом.
- **Миниатюры** декодируются сразу в размер карточки (длинный скриншот 1080×9000 не занимает 40 МБ). Последние 48 хранятся в кэше, повторные запросы одной картинки делят одно декодирование.
- **Частицы спойлера:** два общих сдвига на всё окно, 24 кадра/с, слои кэшируются растром. Работают, только пока окно открыто и в нём есть секреты, а в скрытом состоянии приложение не тратит процессор совсем.
- **Вставка** мгновенная: окно не забирает фокус, поэтому возвращать его не нужно. Если фокус всё же ушёл (после редактирования поиска), ClipNest ждёт ровно до его возврата, без фиксированной паузы.
- **Картинки в буфер** готовятся в фоне: PNG и готовый DIB, остальные форматы Windows достраивает сама. Для 4K-скриншота это ~35 мс на потоке интерфейса вместо ~250 мс.
- **Перехват клавиш с предохранителем:** если интерфейс почему-то перестал принимать клавиши, через 1,5 с перехват отключается сам, и клавиатура не «пропадает».

## Безопасность данных

- **Вся история зашифрована на диске.** База — SQLCipher (AES-256), ключ выведен из `secret.key`, а тот защищён DPAPI вашей
  учётной записи Windows. Картинки, и обычные, и секретные, хранятся зашифрованными через DPAPI. Без входа в ваш
  аккаунт историю не прочитать: ни с другой учётной записи, ни сняв диск, ни из резервной копии папки. Удалённые
  записи затираются (`secure_delete`), старые открытые файлы перед удалением затираются нулями.
- **Права на папку**: только ваша учётная запись и SYSTEM. На втором диске (D:\ и т. п.) папка по умолчанию наследует
  «Прошедшие проверку: изменение», то есть доступ для любой учётной записи на компьютере; ClipNest это убирает.
- **Чего шифрование не закрывает**: программы, запущенные под вашей же учётной записью (в том числе вредоносные),
  могут расшифровать историю так же, как сам ClipNest, и читать буфер обмена напрямую. Этого не закрывает ни одна
  программа для буфера. Если пароль Windows сбросит администратор (не сменить самому, а именно сбросить), ключ DPAPI
  теряется, и история становится нечитаемой: ClipNest откладывает её как `history.db.unreadable-…` и начинает новую.
- **Сам буфер Windows**: если включён журнал буфера Windows (Параметры → Система → Буфер обмена), он хранит свою копию
  всего, что вы копируете. Секреты, которые вставляет ClipNest, туда не попадают, а скопированное в других программах
  попадает. С ClipNest журнал Windows можно выключить.
- **Диск**: запись идёт только при копировании и вставке: ~50 КБ на копию текста, ~150 КБ на скриншот. В покое ничего не
  пишется. Даже сотни копий в день — это единицы ГБ в год.

## Данные

Данные лежат в `Документы\ClipNest`: `history.db`, папка `images\`, `settings.json`, `secret.key`, `clipnest.log`.
Срок хранения (Настройки → «Сколько дней хранить», по умолчанию 0, то есть бессрочно) соблюдается и во время работы,
а не только при запуске: запись удаляется через несколько секунд после того, как с её последнего копирования или вставки
прошло столько дней. Закреплённые не удаляются. ClipNest просыпается для этого только к сроку очередной записи (и не реже
раза в час); проверка, которой нечего удалять, ничего не пишет на диск.
Папку можно сменить в настройках («Данные → Папка с данными»): история переносится туда, ClipNest перезапускается.
Если выбрать непустую папку, данные лягут в подпапку `ClipNest`. Выбранный путь хранится в реестре (`HKCU\Software\ClipNest`, `DataDir`).
Данные из старого места (`%LOCALAPPDATA%\ClipNest`) переносятся автоматически при первом запуске.
Если рядом с exe положить файл `portable.txt`, данные будут храниться в папке `data\` рядом с программой.

Параметры запуска: `--tray` (запуск без показа окна), `--exit` (закрыть запущенную копию).

Для разработки (запускать с отдельной папкой данных через `portable.txt`):
- `--snapshot <папка>`: отрисовать окна в обеих темах в PNG;
- `--screencheck <папка>`: показать окно поверх однотонного фона и снять этот участок экрана, чтобы увидеть системные углы и тень;
- `--layoutcheck <папка>`: разложить окно истории и настройки на сетке мониторов, размеров, масштабов и состояний (за пределами экрана,
  без фокуса и ввода) и записать в `report.txt` всё обрезанное, вылезающее и наложившееся, с картинками;
- `--profile <файл>`: замерить время открытия, поиск, процессор и память;
- `--hooktest <файл>`: проверить перехват Win+V (записывает нажатия в файл и окно не открывает).

## Ограничения

- Win+V не перехватывается, пока активно окно программы, запущенной от администратора: так устроена защита Windows.
  В таких окнах откроется встроенный буфер. По той же причине нельзя вставить в такое окно: запись останется в буфере, и её можно вставить вручную через Ctrl+V.
- Если открыть историю из трея, вставлять некуда: выбранная запись просто копируется в буфер.
- Пока окно не забирает фокус, буквы в поиск попадают напрямую с клавиатуры, без IME: иероглифы (китайский пиньинь и т. п.)
  так не набрать. Кликните в поле поиска, и там работает обычный ввод, включая IME.
